# Changelog

## 0.1.1 — 2026-10-21

- First release published by the tag-triggered OIDC workflow; no runtime changes.
- npm provenance is generated by trusted publishing.
- The release workflow skips publishing when the version already exists and creates
  the GitHub release idempotently.

## 0.1.0 — 2026-10-21

- Published to npm as `dsh-web-ask-aside@0.1.0` and tagged `v0.1.0` on GitHub.
- Initial project scaffold: Host bundle row, Client selection trigger, forked side
  session in the right sidebar, quoted composer draft, live tab title, en/zh copy.
- Build: ESM Host entry plus a `window.__ModuleLoader__` browser factory.
- Tests: pure address/draft logic, locale metadata, and the fork/open/seed wiring.
